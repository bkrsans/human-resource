# Product Requirements

상태: 기준

## 제품 목적

Project Combination Engine은 인재 프로필과 관계를 구조화하고 시각화하여 프로젝트 및 조직 구성을 지원한다. 사용자는 자신에게 격리된 데이터 공간에서 인재 풀과 여러 관계망을 관리하고, 파일 또는 자연어로 데이터를 교환할 수 있어야 한다.

## 사용자 기능

### 인재 관리

- 인재를 추가하고 전체 프로필을 조회한다.
- 이름, 소속 및 키워드로 실시간 검색한다.
- 전문 분야 태그로 필터링한다.
- 목록과 카드 표현에서 인재를 탐색한다.

### 역량 및 관계 시각화

- 실행력, 분석 및 연구력, 창업가 성향, 글로벌 역량을 레이더 차트로 본다.
- 인물 간 친밀도 또는 시너지를 관계망으로 본다.
- 연결 관계를 강조하고 노드를 이동하며 화면을 확대, 축소, 이동한다.

### 데이터 작업

- 표준 Markdown으로 인재를 일괄 가져오고 내보낸다.
- JSON으로 전체 데이터를 백업하고 복원한다.
- 자연어 기록을 서버에서 분석해 구조화된 인재 후보로 변환한다.
- 검증된 후보를 사용자가 확인한 후 현재 데이터에 반영한다.

### 네트워크 관리

- 프로젝트 또는 부서별 네트워크를 생성한다.
- 네트워크를 전환, 복제 및 삭제한다.
- 삭제 전 명시적인 확인을 거친다.

### 계정 관리

- 이메일, 실명, 소속, 직책 및 비밀번호로 가입한다.
- 로그인하고 로그아웃한다.
- 프로필과 비밀번호를 별도 절차로 변경한다.
- 개발 또는 시연 환경에서는 데모 계정을 사용할 수 있다.

## 시스템 품질

- 사용자별 데이터가 계정 간에 노출되거나 섞이지 않는다.
- 데스크톱과 모바일에서 동일한 핵심 기능을 제공한다.
- 라이트 및 다크 테마를 지원한다.
- 키보드, 포커스, 레이블 및 색상 대비 요구사항을 지킨다.
- 파일, API 요청 및 AI 응답은 상태 반영 전에 검증한다.
- 민감한 자격 증명은 서버 밖으로 노출하지 않는다.

## 범위 밖

다음 항목은 별도 결정 전까지 필수 기능으로 간주하지 않는다.

- 특정 UI 브랜드 또는 시각 스타일의 복제
- 특정 AI 공급자나 모델에 대한 영구 종속
- 고정된 포트, 호스트 또는 배포 환경
- 여러 사용자가 하나의 네트워크를 동시에 편집하는 기능
- 외부 조직의 인증·권한 시스템과의 통합

## 완료 판단

제품 완료 여부는 [인수 체크리스트](../quality/acceptance-checklist.md)로 판단한다. 세부 동작은 프론트엔드·백엔드 기능 문서와 공유 계약을 따른다.
