# Natural Language Analysis API

상태: 기준

## 목적

사용자가 제공한 메모, 회의록, 인터뷰 기록 또는 이력 덤프를 검증된 인재 후보 배열로 변환한다. 엔드포인트 경로와 공급자별 설정은 구현 설정에서 관리하고 이 계약의 의미는 유지한다.

## 요청

- 메서드: 본문을 전송할 수 있는 HTTP 메서드
- 콘텐츠 유형: JSON
- 필수 값: 분석할 자연어 원문 문자열

검증:

- 본문이 객체여야 한다.
- 원문은 공백 제거 후 비어 있지 않아야 한다.
- 원문은 설정된 최대 크기를 넘지 않아야 한다.
- 예상하지 않은 형식은 외부 서비스 호출 전에 거부한다.

## 성공 응답

성공 시 [공용 데이터 모델](../shared/data-model.md)에 맞는 인재 후보 배열을 반환한다. 후보는 다음을 표현할 수 있다.

- 식별자와 이름
- 네 가지 역량 점수
- 전문 분야 태그와 에너지 비용
- 존재하는 연락처
- 사실, 해석 및 전략적 적합도
- 원문에서 확인된 인물 간 연결 관계

선택 정보가 원문에 없으면 억지로 생성하지 않는다. 연결 대상은 결과 배열 안에서 확인 가능해야 한다.

## 오류 응답

오류는 다음과 같은 안정된 범주를 구분한다.

- 잘못된 요청 또는 빈 원문
- 허용 크기 초과
- 서버 AI 설정 누락
- 외부 AI 서비스의 일시적 또는 영구적 실패
- AI 출력 파싱 실패
- AI 출력 스키마 검증 실패
- 예기치 않은 서버 오류

응답에는 기계가 판별할 수 있는 오류 코드와 사용자에게 표시 가능한 안전한 메시지를 포함한다. 자격 증명, 내부 스택 및 민감한 원문은 포함하지 않는다.

## 클라이언트 반영 규칙

성공 응답은 즉시 영속 데이터가 되지 않는다. 클라이언트는 후보를 별도 상태에서 보여주고 사용자의 확인 후 현재 사용자 데이터에 반영한다.

## 검증 예시

- 빈 문자열은 외부 호출 없이 거부된다.
- 너무 큰 본문은 외부 호출 없이 거부된다.
- JSON이 아닌 요청은 안전한 형식 오류를 반환한다.
- 존재하지 않는 관계 대상을 가진 AI 결과는 거부된다.
- 외부 공급자 오류 본문은 그대로 전달되지 않는다.
