# Backend Architecture

상태: 기준

## 책임

백엔드는 자연어 분석 API, 외부 AI 연동, 응답 검증, 비밀 관리 및 웹 애플리케이션 제공을 담당한다. 클라이언트가 검증할 수 있다는 가정에 의존하지 않는다.

## 실행 모드

### 개발

- 프론트엔드 개발 서버와 통합해 빠른 갱신과 자산 제공을 지원한다.
- API 경로는 애플리케이션 서버가 직접 처리한다.
- 개발 오류도 비밀 값이나 민감한 원문을 브라우저에 노출하지 않는다.

### 운영

- 빌드된 정적 SPA 자산을 제공한다.
- 알려지지 않은 비-API GET 경로는 SPA 진입점으로 처리한다.
- 알 수 없는 API 경로를 SPA로 처리하지 않고 API 오류로 반환한다.
- 서버 코드는 배포 가능한 Node.js 산출물로 빌드하고 실행한다.

## 구성

- 포트, 호스트, 실행 환경 및 외부 AI 설정은 런타임 설정으로 주입한다.
- 필수 설정은 시작 시 검증하거나 해당 기능 호출 시 안전하게 실패한다.
- 비밀 설정은 클라이언트 환경 변수나 정적 번들에 주입하지 않는다.

## 요청 처리 경계

1. 경로와 HTTP 메서드를 판별한다.
2. 콘텐츠 유형과 본문 크기를 제한한다.
3. 요청 스키마를 검증한다.
4. 도메인 작업 또는 외부 AI 호출을 수행한다.
5. 결과를 공용 데이터 계약으로 검증한다.
6. 안정된 성공 또는 오류 응답으로 변환한다.
