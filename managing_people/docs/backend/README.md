## 공통 구현 규칙

- 모든 외부 입력은 사용 전에 타입, 크기 및 의미를 검증한다.
- 비밀 값은 서버 런타임에서만 읽으며 응답과 로그에 포함하지 않는다.
- AI 공급자의 응답은 신뢰하지 않고 애플리케이션 데이터 계약으로 재검증한다.
- API 오류는 안정된 형식으로 반환하며 내부 구현 세부사항을 노출하지 않는다.
- 실행 환경의 포트, 호스트, 공급자 및 모델은 설정으로 주입한다.
