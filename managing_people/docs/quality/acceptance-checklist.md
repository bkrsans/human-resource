# Acceptance Checklist

상태: 기준

기능 완료는 코드 작성뿐 아니라 아래 관련 항목의 검증을 포함한다. 자동화할 수 없는 항목은 검증 환경과 결과를 변경 기록에 남긴다.

## 계정과 격리

- [ ] 이메일, 실명, 소속, 직책 및 비밀번호로 가입할 수 있다.
- [ ] 비밀번호 강도 피드백이 동작한다.
- [ ] 로그인과 로그아웃이 동작한다.
- [ ] 프로필 수정과 별도 확인을 거친 비밀번호 변경이 동작한다.
- [ ] 계정 전환 후 이전 사용자의 인재와 네트워크가 보이지 않는다.
- [ ] 사용자별 저장소 데이터가 서로 덮어써지지 않는다.
- [ ] 손상된 사용자 저장 데이터가 다른 사용자 상태에 섞이지 않는다.

## 인재 풀

- [ ] 인재를 추가하고 카드 또는 목록에서 볼 수 있다.
- [ ] 이름, 소속 및 키워드 검색이 즉시 반영된다.
- [ ] 전문 분야 태그 필터가 동작한다.
- [ ] 검색과 필터를 함께 적용할 수 있다.
- [ ] 상세 패널에서 전체 프로필을 확인할 수 있다.
- [ ] 추가 입력 오류가 기존 데이터에 영향을 주지 않는다.

## 역량 시각화

- [ ] 실행력, 분석 및 연구력, 창업가 성향, 글로벌 역량을 모두 표시한다.
- [ ] 네 축이 동일한 척도를 사용한다.
- [ ] 프로필 변경이 차트에 즉시 반영된다.
- [ ] 숫자 텍스트 대안과 테마별 충분한 대비를 제공한다.

## 네트워크 맵

- [ ] 인물 노드와 관계선이 데이터에 맞게 표시된다.
- [ ] 선택 노드와 연결 노드가 강조된다.
- [ ] 노드 드래그, 확대, 축소 및 화면 이동이 동작한다.
- [ ] 네트워크 전환 시 이전 그래프 상태가 섞이지 않는다.
- [ ] 잘못된 관계 참조를 안전하게 거부한다.
- [ ] 목표 데이터 규모에서 상호작용 가능한 성능을 유지한다.

## 다중 네트워크

- [ ] 네트워크를 생성하고 전환할 수 있다.
- [ ] 복제본이 새 식별자를 가지며 원본과 독립적으로 변경된다.
- [ ] 삭제 전에 명확한 확인을 요구한다.
- [ ] 삭제가 다른 네트워크나 사용자 데이터에 영향을 주지 않는다.

## 데이터 스튜디오

- [ ] 표준 Markdown을 가져오고 내보낼 수 있다.
- [ ] Markdown 내보내기와 재가져오기가 의미상 왕복된다.
- [ ] JSON으로 전체 데이터를 백업하고 복원할 수 있다.
- [ ] 지원하지 않는 버전과 잘못된 참조를 복원 전에 거부한다.
- [ ] 가져오기·복원 실패 시 기존 데이터를 유지한다.
- [ ] 개인정보가 포함되는 작업은 명시적인 사용자 동작으로 시작한다.

## 자연어 분석

- [ ] 빈 입력, 잘못된 형식 및 과도한 입력을 외부 호출 전에 거부한다.
- [ ] 결과가 공용 인재 데이터 스키마에 맞는다.
- [ ] 원문에 없는 선택 정보를 억지로 생성하지 않는다.
- [ ] 관계 대상과 점수 범위를 서버에서 검증한다.
- [ ] AI 및 공급자 오류를 안전한 API 오류로 변환한다.
- [ ] 사용자가 확인하기 전 결과를 영속 데이터에 반영하지 않는다.

## 보안

- [ ] AI 키와 기타 비밀이 클라이언트 번들에 포함되지 않는다.
- [ ] 비밀이 응답, 로그, JSON 또는 Markdown 내보내기에 포함되지 않는다.
- [ ] 내부 스택과 민감한 원문이 API 오류에 노출되지 않는다.
- [ ] 외부 AI에는 필요한 최소 데이터만 전송한다.

## UI와 접근성

- [ ] 데스크톱과 모바일에서 모든 핵심 흐름이 동작한다.
- [ ] 라이트 및 다크 테마에서 내용을 읽을 수 있다.
- [ ] 주요 작업을 키보드로 완료할 수 있다.
- [ ] 모달의 포커스 진입, 제한, 복귀 및 닫기가 동작한다.
- [ ] 서비스 상태, 로컬 데이터 보호, 이용약관 및 개인정보처리방침을 확인할 수 있다.

## 서버와 배포

- [ ] 개발 환경에서 프론트엔드 개발 서버와 API가 함께 동작한다.
- [ ] 운영 환경에서 정적 SPA와 API를 제공한다.
- [ ] 비-API 클라이언트 경로는 SPA 진입점으로 처리한다.
- [ ] 알 수 없는 API 경로는 SPA가 아닌 API 오류를 반환한다.
- [ ] 서버를 배포 가능한 Node.js 산출물로 빌드하고 실행할 수 있다.
