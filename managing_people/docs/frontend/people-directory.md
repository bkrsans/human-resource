# People Directory

상태: 기준

## 목적

사용자가 현재 네트워크의 인재를 빠르게 탐색하고 필요한 프로필을 찾거나 추가할 수 있게 한다.

## 목록과 카드

- 현재 사용자의 선택된 네트워크에 속한 인재만 표시한다.
- 이름과 핵심 프로필 정보를 식별 가능한 시각적 위계로 제공한다.
- 빈 인재 풀에는 추가 작업으로 이어지는 안내를 제공한다.
- 큰 목록에서도 검색과 스크롤이 사용 가능한 성능을 유지한다.

## 검색과 필터

- 입력 변화에 따라 별도 제출 없이 결과를 갱신한다.
- 이름, 소속 및 검색 가능한 키워드를 대상으로 한다.
- 전문 분야 태그 필터를 제공한다.
- 검색어와 태그 필터를 함께 적용한다.
- 결과가 없을 때 현재 조건을 해제할 수 있는 안내를 제공한다.

## 인재 추가

- 명시적인 사용자 작업으로 추가 모달을 연다.
- 필수 값, 역량 점수 범위 및 연락처 형식을 검증한다.
- 식별자 중복과 현재 네트워크 소유권을 확인한다.
- 검증 실패 시 모달의 입력을 보존하고 필드별 오류를 제공한다.
- 성공 시 현재 사용자와 현재 네트워크에만 추가한다.

## 상세 패널

- 인재 선택 시 전체 프로필, 역량, 전문 분야 및 관계 정보를 표시한다.
- 작은 화면과 큰 화면 모두에서 닫기와 내용 탐색이 가능해야 한다.
- 열릴 때 적절한 위치로 포커스를 이동하고 닫힐 때 호출 요소로 복귀한다.
- 선택 인재가 삭제되거나 네트워크가 바뀌면 오래된 상세 상태를 닫는다.

## 검증 기준

- 검색과 필터 결과가 결합 조건에 맞는다.
- 다른 사용자나 다른 네트워크의 인재가 나타나지 않는다.
- 추가 후 목록, 상세 및 시각화가 같은 데이터를 표시한다.
- 키보드만으로 검색, 필터, 추가 및 상세 닫기가 가능하다.
