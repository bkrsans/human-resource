# Data Studio

상태: 기준

## 목적

사용자가 인재와 네트워크 데이터를 Markdown, JSON 및 자연어로 안전하게 교환하도록 한다.

## Markdown 가져오기

1. 사용자가 표준 템플릿의 텍스트 또는 파일을 선택한다.
2. 현재 상태와 분리된 임시 영역에서 파싱한다.
3. 필수 필드, 점수, 식별자 및 관계 참조를 검증한다.
4. 결과와 오류를 적용 전에 보여준다.
5. 사용자 확인 후 현재 사용자 데이터에 반영한다.

파싱 또는 검증 실패 시 기존 데이터를 변경하지 않는다.

## Markdown 내보내기

- 현재 사용자가 선택한 범위의 인재와 관계를 표준 템플릿으로 만든다.
- 존재하지 않는 선택 값을 임의 생성하지 않는다.
- 내보낸 결과는 의미 손실 없이 다시 가져올 수 있어야 한다.

## JSON 백업과 복원

- 백업은 전체 사용자 네트워크 데이터를 형식 버전과 함께 파일로 제공한다.
- 계정 자격 증명과 서버 비밀은 제외한다.
- 복원 전에 파일 구조, 크기, 버전 및 전체 참조 무결성을 검증한다.
- 덮어쓸 범위와 영향을 알리고 명시적인 확인을 받는다.
- 복원 실패 시 이전 상태를 유지한다.

## 자연어 분석

- 메모, 회의록, 인터뷰 기록 및 이력 덤프를 입력할 수 있다.
- 서버 전송 전에 개인정보가 외부 AI 처리에 사용됨을 안내한다.
- 사용자의 명시적 실행 없이 원문을 전송하지 않는다.
- 로딩 중 중복 제출을 방지하고 취소 또는 실패 상태를 처리한다.
- 분석 결과는 기존 데이터와 분리된 후보 목록으로 표시한다.
- 사실, 해석 및 전략적 적합도를 구분해 검토할 수 있게 한다.
- 사용자가 승인한 결과만 현재 사용자 데이터에 반영한다.
