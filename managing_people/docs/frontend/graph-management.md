# Graph Management

상태: 기준

## 목적

프로젝트 또는 부서별로 독립된 네트워크를 만들고 빠르게 전환, 복제 및 삭제하도록 한다.

## 생성

- 네트워크 이름과 필요한 메타데이터를 입력받는다.
- 현재 사용자 범위에서 새 식별자를 발급한다.
- 생성 후 해당 네트워크로 전환하거나 결과를 명확히 알린다.
- 이름 중복 허용 여부를 일관되게 적용하며 식별자는 항상 유일해야 한다.

## 전환

- 현재 네트워크를 식별 가능하게 표시한다.
- 전환 시 대상 네트워크의 인재, 관계, 선택 및 화면 상태만 불러온다.
- 저장되지 않은 편집이 있다면 손실 전에 사용자에게 알린다.
- 다른 사용자의 네트워크를 선택 항목으로 노출하지 않는다.

## 복제

- 새 네트워크 식별자를 발급한다.
- 인재와 관계의 내부 참조를 유지한다.
- 복제본의 이름을 사용자가 구분할 수 있게 한다.
- 원본과 복제본의 이후 변경은 서로 독립적이어야 한다.

## 삭제

- 삭제 대상과 복구 불가능성을 명확히 표시한다.
- 별도의 명시적 확인 후 삭제한다.
- 삭제 취소 시 아무 데이터도 변경하지 않는다.
- 현재 네트워크를 삭제한 경우 안전한 다른 네트워크를 선택하거나 빈 상태를 제공한다.
- 다른 네트워크와 다른 사용자 데이터에는 영향을 주지 않는다.
