# Competency Visualization

상태: 기준

## 목적

선택한 인재의 핵심 역량을 동일한 척도의 방사형 레이더 차트로 비교 가능하게 표현한다.

## 축

차트는 다음 네 축을 모두 표시한다.

- 실행력
- 분석 및 연구력
- 창업가 성향
- 글로벌 역량

## 렌더링 규칙

- 모든 축은 같은 최소·최대 범위를 사용한다.
- 값은 데이터 모델의 유효 범위 안에서만 렌더링한다.
- 프로필 값이 변경되면 차트를 즉시 갱신한다.
- 라이트 및 다크 테마에서 축, 레이블, 데이터 영역의 대비를 유지한다.
- 화면 크기에 맞게 축소되더라도 레이블과 데이터 의미를 잃지 않는다.

## 접근성

- 시각적 차트와 함께 인재 이름, 지표명 및 숫자 값을 텍스트로 제공한다.
- 색상만으로 축이나 값의 차이를 전달하지 않는다.
- 장식용 그래픽은 보조 기술의 중복 읽기를 방지한다.

## 예외 상태

- 인재가 선택되지 않았으면 선택 안내를 표시한다.
- 유효하지 않은 점수는 조용히 왜곡해 그리지 않고 데이터 오류로 처리한다.
- 부분 점수를 허용하지 않는 공용 계약에 따라 네 축 중 누락이 있으면 검증 실패로 본다.
