# Network Graph

상태: 기준

## 목적

현재 네트워크의 인물과 관계 강도 또는 시너지를 상호작용 가능한 물리 기반 관계망으로 보여준다.

## 표현

- 인재는 식별 가능한 노드로 표시한다.
- 연결 관계는 두 인재 사이의 선으로 표시한다.
- 관계 강도 또는 시너지 차이를 일관된 시각 속성으로 표현한다.
- 선택한 노드와 직접 연결된 노드를 강조하고 무관한 요소는 구분 가능하게 약화할 수 있다.

## 상호작용

- 노드를 포인터로 드래그하여 위치를 재배치한다.
- 확대 및 축소를 지원한다.
- 화면 이동을 지원한다.
- 노드 선택은 인재 상세 정보와 연결될 수 있다.
- 드래그와 화면 이동 동작이 충돌하지 않도록 입력 상태를 구분한다.

## 물리 시뮬레이션

- 노드 겹침을 줄이고 연결 관계를 읽을 수 있는 초기 배치를 제공한다.
- 사용자가 이동한 노드는 의도한 위치를 안정적으로 유지하거나 고정 해제 방식을 제공한다.
- 안정 상태에 가까워지면 불필요한 계산을 줄인다.
- 컴포넌트 종료, 네트워크 전환 및 탭 비활성화 시 애니메이션 자원을 정리한다.

## 데이터 무결성

- 존재하지 않는 인재를 가리키는 관계는 렌더링 전에 거부한다.
- 네트워크 전환 시 이전 네트워크의 노드, 선택 및 화면 상태가 섞이지 않는다.
- 인재나 관계 변경은 다시 로드하지 않아도 반영된다.

## 성능과 접근성

- 데이터 규모 증가 시 렌더링과 물리 계산이 입력을 장시간 차단하지 않아야 한다.
- 캔버스 또는 그래픽만으로 정보를 제공하지 않고 선택 인재와 관계의 텍스트 대안을 제공한다.
- 확대·축소·이동의 키보드 또는 동등한 컨트롤을 제공한다.
- 동작 감소 환경 설정을 존중해 불필요한 움직임을 줄인다.
