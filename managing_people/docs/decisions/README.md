# Architecture Decision Records

상태: 기준

ADR은 되돌리기 어렵거나 여러 영역에 장기 영향을 주는 결정을 기록한다. 작은 구현 세부사항이나 일시적인 작업 메모는 기록하지 않는다.

## 작성 대상

- 데이터 저장 방식 또는 사용자 격리 전략 변경
- 공용 데이터 계약의 호환성을 깨는 변경
- 인증, 비밀 관리 또는 외부 AI 공급자 경계 변경
- 렌더링·상태 관리·서버 구조의 핵심 방식 변경
- 새로운 운영 의존성 도입

## 파일 규칙

- 파일명은 `NNNN-short-title.md` 형식을 사용한다.
- 번호는 기존 최대 번호 다음 값을 사용한다.
- 상태는 `제안`, `승인`, `대체`, `폐기` 중 하나로 기록한다.
- 대체된 ADR은 삭제하지 않고 새 ADR 링크를 남긴다.
- 기본 형식은 [ADR 템플릿](../templates/adr.md)을 사용한다.
