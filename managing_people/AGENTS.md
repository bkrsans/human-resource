# Project Combination Engine

전략적 인적자원 네트워크 분석 시스템을 구현하고 유지하기 위한 프로젝트 지침이다. 이 문서는 변경 가능성이 큰 버전, 포트, 호스트, AI 모델명, 저장소 키 이름 및 시각 스타일의 세부 수치를 고정하지 않는다. 구현 방식이 바뀌더라도 아래 기능과 데이터 보호 원칙은 유지해야 한다.

## 문서 하네스

- 이 파일은 제품의 불변 원칙과 필수 완료 기준을 정의하는 최상위 기준 문서다.
- 구현 가능한 상세 명세와 문서 지도는 [`docs/README.md`](docs/README.md)에서 관리한다.
- 문서가 충돌하면 `AGENTS.md`, `docs/shared/`의 공용 계약, 프론트엔드·백엔드 기능 명세 순으로 우선한다.
- 작업 전 관련 기능 명세, 공용 데이터 계약, 보안 문서 및 인수 체크리스트를 확인한다.
- 기능 동작을 변경할 때 구현 코드와 관련 문서 및 체크리스트를 같은 변경에서 갱신한다.
- 데이터 모델 변경은 UI, 파일 입출력 및 AI 응답 계약에 미치는 영향을 함께 반영한다.
- 인증, 저장, 가져오기, 내보내기 또는 외부 AI 전송 변경은 사용자 격리와 개인정보 보호 문서를 반드시 검토한다.
- 장기간 영향을 주거나 되돌리기 어려운 기술 결정은 `docs/decisions/`에 ADR로 기록한다.
- 상세 문서에도 변경 가능성이 큰 버전, 포트, 호스트, 모델명 및 비밀 값은 고정하지 않는다.

## 제품 목표

- 인재 프로필을 등록, 탐색, 검색하고 전문 분야별로 분류한다.
- 개인 역량과 인물 간 관계를 시각화하여 프로젝트 및 조직 구성에 활용한다.
- 프로젝트나 부서별로 독립된 네트워크 맵을 관리한다.
- JSON, Markdown 및 자연어 입력을 통해 데이터를 가져오고 내보낸다.
- 사용자별 데이터를 격리하고 민감한 AI 자격 증명을 서버에서만 관리한다.

## 프론트엔드 요구사항

### 공통 UI/UX

- 명확한 시각적 위계와 모듈형 카드 중심의 반응형 인터페이스를 제공한다.
- 화면 크기에 관계없이 핵심 기능을 사용할 수 있어야 한다.
- 라이트 테마와 다크 테마를 전환할 수 있어야 한다.
- 상태 변화와 화면 전환에는 사용성을 해치지 않는 피드백을 제공한다.
- 서비스 상태와 로컬 데이터 보호 안내를 표시한다.
- 서비스 이용약관 및 개인정보처리방침을 모달로 열람할 수 있어야 한다.

### 인재 풀

- 등록된 인재를 목록 및 카드 형태로 탐색할 수 있어야 한다.
- 이름, 소속 및 키워드를 실시간으로 검색할 수 있어야 한다.
- 전문 분야 태그로 인재를 필터링할 수 있어야 한다.
- 모달을 통해 새 인재를 간편하게 추가할 수 있어야 한다.
- 인재를 선택하면 반응형 상세 패널에서 전체 프로필을 확인할 수 있어야 한다.

### 역량 시각화

- 각 인재의 핵심 역량을 방사형 레이더 차트로 렌더링한다.
- 다음 네 가지 지표를 모두 표현한다.
  - 실행력
  - 분석 및 연구력
  - 창업가 성향
  - 글로벌 역량
- 프로필 데이터가 변경되면 차트가 즉시 갱신되어야 한다.

### 네트워크 맵

- 물리 기반 관계망 시뮬레이션으로 인물 노드와 관계선을 시각화한다.
- 관계선은 인물 간 친밀도 또는 시너지를 표현할 수 있어야 한다.
- 선택한 노드와 연결된 노드를 시각적으로 강조한다.
- 노드를 드래그하여 위치를 재배치할 수 있어야 한다.
- 확대, 축소 및 화면 이동을 지원한다.
- 데이터 규모가 커져도 상호작용 가능한 수준의 렌더링 성능을 유지한다.

### 데이터 스튜디오

- 표준화된 Markdown 템플릿을 사용해 인재 프로필을 일괄 가져올 수 있어야 한다.
- 현재 데이터를 Markdown으로 내보낼 수 있어야 한다.
- 전체 데이터를 JSON 파일로 백업하고 복원할 수 있어야 한다.
- 메모, 회의록, 인터뷰 기록 및 이력 덤프 등의 자연어를 입력해 서버의 AI 분석 API를 호출할 수 있어야 한다.
- 가져오기와 복원 전에 입력을 검증하고, 실패 시 기존 데이터를 손상시키지 않아야 한다.
- Markdown과 내부 인재 데이터 모델 간 양방향 변환을 제공한다.

### 다중 네트워크 관리

- 프로젝트 또는 부서 단위로 독립된 네트워크 맵을 생성할 수 있어야 한다.
- 네트워크 맵을 빠르게 전환, 복제 및 삭제할 수 있어야 한다.
- 삭제처럼 복구가 어려운 작업에는 명확한 확인 절차를 둔다.

### 계정 및 프로필

- 이메일, 실명, 소속, 직책 및 비밀번호를 입력받아 회원가입할 수 있어야 한다.
- 비밀번호 강도를 측정해 사용자에게 표시한다.
- 로그인과 로그아웃을 지원한다.
- 개발 또는 시연 환경에서는 데모 계정 전환 기능을 제공할 수 있다.
- 사용자가 자신의 프로필 정보를 수정할 수 있어야 한다.
- 별도 확인 절차를 거쳐 비밀번호를 변경할 수 있어야 한다.

### 상태 관리와 데이터 격리

- 인증 상태는 현재 세션과 등록된 계정 정보를 일관되게 관리한다.
- 인재 풀과 네트워크 맵은 로그인한 사용자의 고유 식별자를 기준으로 분리해 영속화한다.
- 계정을 전환해도 다른 사용자의 인재 또는 네트워크 데이터가 노출되거나 섞여서는 안 된다.
- 브라우저 저장소를 사용할 경우 사용자별 네임스페이스를 적용하고 직렬화 실패를 안전하게 처리한다.

## 백엔드 요구사항

### 애플리케이션 서버

- Node.js 기반 HTTP 서버에서 API를 제공한다.
- 개발 환경에서는 프론트엔드 개발 서버 및 빠른 갱신 기능과 통합한다.
- 운영 환경에서는 빌드된 정적 SPA를 제공한다.
- 클라이언트 라우팅을 위해 알 수 없는 비-API 경로를 SPA 진입점으로 처리한다.
- 서버 코드를 배포 가능한 Node.js 번들로 빌드하고 실행할 수 있어야 한다.
- 포트, 호스트 및 실행 환경은 환경 변수나 실행 설정으로 구성할 수 있어야 한다.

### 자연어 분석 API

- 클라이언트가 자연어 원문을 전송할 수 있는 분석 엔드포인트를 제공한다.
- 요청 본문을 검증하고 빈 입력, 과도한 입력 및 잘못된 형식에 적절한 오류를 반환한다.
- 서버에서 생성형 AI 서비스를 호출해 비정형 텍스트를 구조화된 인재 데이터로 변환한다.
- AI 응답에 구조화된 출력 스키마를 강제하거나, 동등한 수준의 서버 측 스키마 검증을 수행한다.
- AI 제공자 오류, 응답 형식 오류 및 일시적 장애를 클라이언트가 처리 가능한 형태로 반환한다.

### AI 추출 데이터 계약

분석 결과는 인재 배열을 반환하며, 문맥에 값이 없는 선택 항목을 억지로 생성하지 않는다. 최소한 다음 데이터를 표현할 수 있어야 한다.

- 인물 식별자와 이름
- 실행력, 분석 및 연구력, 창업가 성향, 글로벌 역량 점수
- 전문 분야 태그
- 에너지 비용
- 이메일과 전화번호
- 사실 기반 이력
- 정성적 성향 해석
- 조직 또는 프로젝트에 대한 전략적 적합도
- 텍스트에서 확인된 인물 간 연결 관계

식별자, 점수 범위, 관계 대상 및 필드 타입은 서버에서 검증한다. 사실과 해석을 분리하고, 원문으로 확인할 수 없는 개인정보나 관계를 추측하지 않는다.

### 보안

- AI API 키와 기타 비밀 값은 서버 환경에서만 읽는다.
- 비밀 값이 클라이언트 번들, 응답, 로그 또는 저장소에 포함되어서는 안 된다.
- 외부 AI 서비스에는 기능 수행에 필요한 최소 데이터만 전송한다.
- API 오류 메시지에 자격 증명, 내부 스택 또는 민감한 사용자 데이터를 노출하지 않는다.
- 개인정보를 다루는 가져오기, 내보내기 및 분석 흐름에 명시적인 사용자 동작이 필요하다.

## 핵심 데이터 흐름

1. 인증 계층이 현재 사용자를 식별한다.
2. 사용자별 상태 계층이 해당 사용자의 인재 풀과 네트워크 맵만 불러온다.
3. UI에서 인재를 탐색, 수정하고 역량 및 관계망을 시각화한다.
4. 데이터 스튜디오가 JSON 및 Markdown 입출력을 처리한다.
5. 자연어 분석 요청은 서버 API로 전송한다.
6. 서버가 비밀 키를 사용해 AI 서비스를 호출하고 결과를 스키마로 검증한다.
7. 검증된 결과만 클라이언트에 반환하며, 사용자가 확인한 뒤 사용자별 데이터에 반영한다.

## 구현 원칙

- 기능을 추가하거나 변경할 때 사용자별 데이터 격리를 최우선으로 검증한다.
- UI에서 사용하는 인재 모델, 파일 입출력 모델 및 AI 응답 모델의 의미를 일치시킨다.
- 외부 입력은 신뢰하지 말고 파일, API 요청 및 AI 응답 경계에서 검증한다.
- 가져오기, 복원 및 AI 분석 결과는 검증 완료 전까지 기존 상태에 반영하지 않는다.
- 접근성 있는 레이블, 키보드 조작, 포커스 관리 및 충분한 색상 대비를 유지한다.
- 구현 세부 기술은 교체할 수 있지만 이 문서의 사용자 기능, 데이터 계약 및 보안 조건을 훼손해서는 안 된다.

## 완료 기준

- 회원가입, 로그인, 로그아웃, 프로필 수정 및 비밀번호 변경 흐름이 동작한다.
- 서로 다른 계정의 데이터가 완전히 격리된다.
- 인재 추가, 탐색, 검색, 필터링 및 상세 조회가 동작한다.
- 네 가지 역량 지표와 인물 관계망이 정확히 시각화된다.
- 네트워크 맵 생성, 전환, 복제 및 삭제가 동작한다.
- JSON 백업 및 복원과 Markdown 가져오기 및 내보내기가 왕복 가능하다.
- 자연어 분석 API가 스키마에 맞는 결과를 반환하고 오류를 안전하게 처리한다.
- 비밀 값이 클라이언트나 저장소에 노출되지 않는다.
- 주요 화면과 상호작용이 데스크톱과 모바일에서 정상 동작한다.
